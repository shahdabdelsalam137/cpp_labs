# C++ Labs

A collection of C++ lab exercises and practical assignments designed to strengthen programming fundamentals, develop problem-solving skills, and improve understanding of core C++ concepts.

## Topics Covered

- Basic Syntax and Data Types
- Conditional Statements and Loops
- Functions and Recursion
- Arrays and Strings
- Pointers and Memory Management
- Problem Solving and Algorithms
- Practical Programming Exercises

## Technologies

- **Language:** C++
- **Compiler:** GCC (G++)
- **IDE:** Visual Studio Code

## Purpose

To practice C++ programming, apply theoretical concepts through hands-on exercises, and build a strong foundation in problem-solving and software development.
